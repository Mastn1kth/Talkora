# Talkora

Рабочий интерактивный прототип обучения английскому для русскоязычных пользователей. В репозитории находятся адаптивный сайт, локальный Node.js API с SQLite и Android-проект Capacitor. Это основа для разработки, а не готовое приложение для публикации.

## Локальный запуск

Нужен Node.js 24 или новее. В каталоге проекта:

```powershell
npm ci
npm run dev
```

Откройте адрес, который покажет Vite (по умолчанию `http://127.0.0.1:5173`). API работает на `http://127.0.0.1:3001`; Vite перенаправляет запросы `/api` на него. База создаётся в `data/talkora.sqlite`; путь можно изменить переменной `DB_PATH`. Для выпуска в интернет серверу нужны HTTPS, домен, резервное копирование, мониторинг и дополнительные проверки безопасности.

Для проверки собранного сайта:

```powershell
npm run build
npm start
```

Сайт будет доступен на `http://127.0.0.1:3001`. После первого открытия сборки service worker сохраняет оболочку приложения; пройденные занятия и личные слова доступны без сети и синхронизируются после подключения. Аудио зависит от голосов устройства и не гарантировано офлайн.

Проверки: `npm test` (сервер, учебная логика, импорт, конфликтная синхронизация) и `npm run build`. Для Android-сборки задайте абсолютный HTTPS origin общего API через `VITE_API_URL` (например, `https://api.example.com`), а на сервере разрешите точный origin приложения и сайта через `APP_ORIGIN=https://localhost,https://talkora.example`. Затем выполните `npm run android:sync` и из каталога `android` запустите `gradlew.bat assembleDebug` с `JAVA_HOME`, указывающим на JDK 21. Debug APK находится в `android/app/build/outputs/apk/debug/app-debug.apk`. Без `VITE_API_URL` нативный клиент явно сообщает, что сервер не подключён; локальный адрес устройства не подменяется сервером. Debug APK собирается, но этот артефакт сделан без реального HTTPS API; на устройстве вход и синхронизация не проверены. Для выпуска нужны общий HTTPS API, релизная подпись и испытания на устройстве.

## Что работает и что пока демонстрационное

Работают регистрация по почте, локальные аккаунты, онбординг, карта четырёх арен, уроки с несколькими типами заданий, мини-тесты, стартовый тест, личные слова, импорт TXT/CSV/XLSX, извлечение текста из PDF и OCR сканов/PNG/JPG/WebP, готовые тематические тренировки, базовый справочник, сохранение состояния на сервере, офлайн-кэш сайта, недельные группы лиг, восстановление серии после одного пропущенного дня и удаление аккаунта. После PDF/OCR распознанный текст можно исправить, затем проверить каждое слово и перевод; файл не отправляется на сервер или сторонний OCR-сервис. PDF ограничен 8 страницами и 8 МБ, изображения — 8 МБ и 40 мегапикселями. Веб-версия при первом OCR получает языковые данные с сервера Talkora и затем может использовать браузерный кеш; Android debug APK уже содержит движок и языковые данные. Качество проверено на простых тестовых файлах, а на реальных фотографиях пока не оценено. Первое восстановление серии бесплатно, следующие стоят 20 кристаллов; восстановление требует интернета и урока в тот же день для продолжения серии. Жалобы сохраняются в базе, но операторская обработка и доставка в службу поддержки ещё не подключены.

Для основных уроков и мини-тестов сервер сверяет первые ответы с опубликованным каталогом, сам пересчитывает точность и допустимую награду и только после этого добавляет очки в недельную лигу. Онлайн-тренировка «Мои слова» получает отдельную серверную сессию, привязанную к аккаунту и конкретному набору упражнений; её проверенные 30 XP тоже входят в лигу. Без сети личные слова остаются доступны, но такое локальное занятие даёт только общий XP. Повторное прохождение одного занятия даёт не более 10 XP. Готовые тематические тренировки пока не попадают в лигу. Проверка закрывает простую подмену счётчиков и ответов, но ответы видны работающему клиенту и это не является защитой от автоматизации, поэтому публичный соревновательный запуск требует дополнительной защиты и испытаний. История, накопленная до появления проверки, не учитывается в лиге.

Произвольная ИИ-генерация тем, автоматический перевод произвольных загруженных слов, Google/Apple OAuth, push-уведомления, подтверждение почты, весь маршрут A1–C2, редакторская админка, студийное British English аудио и полная локализация RU/EN **не реализованы**.
